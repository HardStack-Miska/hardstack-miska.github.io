01

A backend that handles the retry.

For my independent Android productivity application, I built and deployed an asynchronous Rust backend for multiple users and devices.

  • Implemented REST APIs, PostgreSQL transactions, offline synchronization and idempotent operations.
  • Integrated external AI APIs with Reqwest and Serde.
  • Verified behavior with unit and integration tests, manual API requests and multi-device checks.
How I checked it worked

I repeated operations to check for duplicate effects, interrupted network connections, restarted the server and inspected logs and Tracing output. The goal was to understand what happened when clients retried or returned after an interruption, alongside checking normal API behavior.

02

Market data, without imaginary ordering.

In selected freelance and independent cryptocurrency trading projects, I built exchange connectivity and latency-sensitive components using C++, Rust and Python.

  • Integrated Binance, Bybit, KuCoin and OKX APIs.
  • Implemented sequence tracking, event deduplication and asynchronous order-book reconstruction.
  • Processed BBO updates and trade events independently when their arrival order could not establish a reliable shared timeline.
One problem I enjoyed solving

I worked on redundant WebSocket subscriptions that selected the earliest valid copy of an event and discarded later duplicates. I also handled reconnections, timeouts and exchange order lifecycle behavior. The engineering focus was event timeliness and correctness; I do not claim a benchmarked latency improvement.

02 / How I work

AI can write code.
I still own the result.

I use Claude and Codex regularly, and have experimented with a personal multi-agent development workflow. The most useful lesson: keep review close to implementation, before the code drifts away from the plan.

PERSONAL WORKFLOW / HANDS-ON EXPERIMENTATION

  1. 01

    Make the problem small enough to inspect.

    Plan the work in explicit steps, with clear boundaries and a way to check the result.

  2. 02

    Parallel work needs coordination.

    I experimented with planning, development, specialist and validation agents, including context management and parallel tasks.

  3. 03

    Let evidence win the argument.

    I like testing competing approaches. If a colleague has a better explanation or the tests disagree with my idea, I change the approach.
